# 人生の資産
資産の見える化Webアプリ

## 概要
非金融資産（時間・スキル・人間関係・体験・健康）を金銣換算し、総資産額をリアルタイムで表示するブラウザ完結の資産可視化アプリです。毎日1タップで行動が財産形成に直結する体験を提供します。健康タブを最初に追加し、時価計算・API連携を即時反映します。

## 技術スタック
- React 18 + Vite
- Tailwind CSS
- ブラウザネイティブ（PC/スマホ両対応）

## インストール
1. フォルダ「asset-visualization」を作成
2. 上記のソースコードをすべて保存
3. ターミナルでフォルダを開く
4. コマンド実行：
   ```bash
   npm install
   npm run dev
